# Project instructions

- After completing and verifying a requested change, commit and push it to the existing GitHub repository (origin). The user explicitly requests this for every change.
- GitHub Pages automatically publishes the static frontend after pushes to main. Keep the AI backend local unless the user separately authorizes online backend deployment.
- Never commit API keys, .env.local, other secret environment files, .local caches, or generated private artifacts. Check staged files before pushing.
