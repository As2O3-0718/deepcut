# 潜 · Deepcut

中文冷门答案小游戏，每轮7题。当前本机版包含 **210道题**，以及 DeepSeek 出题和判题。

## 运行本机 AI 版

需要 Node.js 22.9+。在项目目录运行：

```powershell
npm start
```

打开 http://127.0.0.1:4173/ 。服务仅监听本机回环地址。关闭终端会停止 AI 服务。

- 普通开局优先抽取此浏览器未玩过的题，记录保存在本机浏览器中。
- 点击“AI 新一轮”生成7道新题；一轮开始答题后，该按钮暂时禁用，结算后可以再用。
- 开启“未收录答案交给 AI 判定”时，仅未命中题库的答案会发送给 DeepSeek。可随时关闭。
- AI 超时、无法确认或不认可答案时可重试/跳过，不自动扣分。
- AI 判定缓存到本机，重启后保留。同一题的规范名称尽量复用相同分值。
- 本机交互服务无每日调用上限；两次 API 调用开始时间至少间隔 2 秒，同时仅处理一个请求。过于频繁时提示剩余等待秒数；间隔记录在本机保存，重启仍生效。已命中题库/缓存的答案不调用 API，不受频率限制。失败请求也占用间隔，日调用量仅用于记录。此规则不包含手动运行题库生成脚本。

## 配置密钥

```powershell
& .\scripts\configure-deepseek.ps1
npm run ai:check
```

隐藏输入的密钥保存在 `.env.local`，只由服务端读取，不会发送给网页。`.env*`、`.dev.vars*`、`.local/` 均被Git忽略（不含无密钥的 `.env.example`）。不要把密钥添加到 dist、离线HTML或GitHub。当前模型默认 `deepseek-flash`，接口为 DeepSeek 官方 `/chat/completions`。

## 题库与可靠性

原始21题为人工预设题库，新增189题由DeepSeek生成并经过第二轮AI复核，另进行了抽查、范围修正和部分剔除。**并非所有事实均已人工核验，AI仍可能误判或编造。** 冷门评分为娱乐性估计，不是玩家回答统计。

`dist/generated.js` 为当前已整理的新增题库。`npm run bank:expand` 会请求AI批量生成及复核候选题，缓存各批次到 `.local/batches/`，汇总到 `.local/candidate-bank.json`；候选题需要人工审核后再合入题库，不能直接发布。单次最多26批，每批最多2次尝试，每次尝试包括生成及复核调用，可能消耗较多Token。

## 验证与离线版

```powershell
npm test
npm run offline
```

`offline/Deepcut.html` 可直接用浏览器打开，只提供本地题库，无AI服务，不需要网络。修改题库后运行 `npm run offline` 更新它。

## 线上部署状态

修改经验证后会提交并推送到 GitHub，GitHub Pages 自动同步题库和界面。AI 后端仍按要求仅在本机运行，尚未配置线上 AI 后端。GitHub Pages 本身不能保存密钥或运行本项目的 Node 后端。

仓库已有GitHub Actions配置：未来推送到main会验证并发布dist目录；静态网页会自动禁用本机AI入口。部署服务器时需要另行配置密钥和访问控制，不能将当前本机服务直接暴露到公网。

玩法参考：https://krillion.io/ 。未使用原站源代码、品牌素材或私人题库。
DeepSeek API 文档：https://api-docs.deepseek.com/

## 满分参考与换题

每题参考答案按题内相对冷门度校准，至少有一个100分答案；100分不是实际玩家回答概率。答对或跳过后显示100分参考，输入该答案也实际获得100分。评分更新会使旧AI判定缓存失效，但不清零当日调用量。

每轮有两次换题机会，仅能在当前题未完成、AI未处理中时使用。换题从本地题库挑选与本轮及已换走题目不重复的题，优先未玩过的题，不扣分、不推进题号，也不额外调用AI。换题时弹窗展示原题参考答案，结算后可回看。下一轮恢复两次机会。

## 严格判题

未收录答案必须同时满足真实存在、单一答案、符合全部题意条件，才能计分。缺失核验信息或解释与结论矛盾时不计分并允许重答；已有错误判定缓存按版本失效。针对已发现的“萨米语不属于印欧语系”等事实错误，前后端均优先应用确定性纠正规则。AI仍不能保证所有事实判断正确。

## 题目与答案反馈

题目、参考答案及判分结果支持赞／踩，再次点击可撤销，也可改票。反馈不自动修改分数。公开网页和离线版保存在当前浏览器，可用顶部“导出反馈”下载 JSON 供人工复核；GitHub Pages 没有集中收集服务。本机版还同步保存到 Git 忽略的 `.local/feedback.json`，无需调用 AI。最多保留最近 2000 条，清除浏览器数据会删除浏览器副本。
