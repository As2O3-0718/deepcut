# 试玩记录（2026-09-27）

本轮由试玩代理发现问题、另一代理修复，并交回试玩代理复测。浏览器工具启动失败，以下为加载真实前端源码、执行事件处理器的 DOM/VM 交互测试，**不是浏览器视觉验收**。AI 响应使用测试替身，没有调用付费 API。

## 1. 编辑答案后重新判定仍提交旧答案

- 步骤：提交“旧答案甲”，模拟 AI 无法确认；将输入改为“改过的新答案乙”；点击“重新判定”。
- 修复前：输入框显示乙，请求正文仍为甲，且设置 `recheck: true`。
- 修复：重新判定读取当前输入，沿用提交校验。
- 回归结果：请求提交乙；再清空输入并点击重新判定，不增加 API 请求、不增加得分，显示输入提示。

## 2. 一个答案点赞会让其他未投票项显示“已撤销”

- 步骤：显示题目、宁夏参考答案及广西参考答案的三个投票控件；仅给宁夏点赞。
- 修复前：三个状态依次显示“已撤销”“已赞”“已撤销”，存储实际上只有一条赞。
- 修复：每个控件记录自己的上次票态，只在自己的票态变化时更新提示。
- 回归结果：未操作项保持空白；题目屏蔽状态不受答案改票影响；跨标签页撤销只更新对应项。

自动回归位于 `tests/playtest-interactions.test.js`。试玩还检查了换题后刷新保留次数、跳过后恢复不重复加分、模拟 AI 出题失败保留原局，未发现异常。

修复后，试玩代理独立重跑这两条交互回归，均通过。完整自动测试 82 项通过，离线版构建通过。
